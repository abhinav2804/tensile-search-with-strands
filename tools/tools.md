# Tools Overview

Supporting stacks and utilities for running Elasticsearch, MCP, and the n8n workflow.

## docker-elk/

Helper ELK stack (Elasticsearch + Kibana) via Docker Compose for local inspection. See files inside the folder for compose and configuration. Use this if you prefer a Kibana UI to inspect indices during demos.

## mcp-server-elasticsearch/

Upstream Elastic MCP server. Contains Dockerfiles, Rust source, and docs to run a full‑featured MCP service. If you don’t use the lightweight sidecar generated by the portal, you can deploy this server and point the Search Agent at it. Refer to the folder’s own `README.md` for build/run steps.

## ElasticMPCServer/

Docker Compose for running an Elastic MCP server (packaged variant) suitable for quick trials. Check the compose and README in that folder for environment variables and ports.

## N8N/

Docker Compose and notes to launch n8n quickly. Use this to host the Search Agent workflow if you don’t already have an n8n instance.

## Context/

Miscellaneous helper context and references used during development.

## tools/README.md

High-level pitch and run instructions for a prior iteration of the project. Cross‑check with the root `README.md` for the most recent flow.
