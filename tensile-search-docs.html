📚 Overview

This hackathon-ready, end-to-end deployment provides a complete search stack that requires zero code to get started. Built for speed and flexibility, it handles everything from raw data ingestion to natural language querying.

Key Capabilities

  • Smart Schema Generation: Automatically generates Elasticsearch mappings from data + intended queries
  • Attribute Extraction: LLM-powered attribute extraction for faceted search
  • Flexible Deployment: Local or remote Elasticsearch with Docker
  • Portal Interface: Simple web interface for upload and search
  • MCP Integration: LLM-driven search capabilities
  • n8n Workflow: Search agent for natural language queries

🚀 What You'll Build

  1. Upload & Configure: Upload a file and paste example queries in the portal
  2. Pipeline Processing: Automatic schema derivation, attribute extraction, and ES document preparation
  3. Deployment Choice: Choose Local or Remote deployment
    • Remote: SSH to VM, run Elasticsearch in Docker, index docs, boot MCP server
  4. Natural Language Search: Use the Search Agent (n8n) with Elastic MCP for filtered queries at speed

🏗️ Architecture

Core Components

Frontend Portal (Flask)

  • frontend/app.py - Simple upload portal with APIs
  • Endpoints: upload, health, MCP status, etc.

EnhancedDataPipeline

  • frontend/enhanced_data_pipeline.py - Parses data, generates schema, extracts attributes
  • Local mode: Indexes into CONFIG['es_host'] (default http://localhost:9200)
  • Remote mode: SSH to VM, run Docker ES, index data, spin up MCP server

MCP for Search

  • tools/mcp-server-elasticsearch - Elastic MCP server
  • frontend/mcp_integration.py - Lightweight server with endpoints:
    • /health, /search, /index-info
    • /capabilities, /prompt

Search Agent

  • search-agent/N8N - Search Agent.json - n8n flow for NL queries

User Registry (Optional)

  • frontend/db_registry.py - Persists per-user ES/MCP endpoints

📋 Prerequisites

  • OS Linux/macOS with Docker installed and running
  • Python Python 3.10+ (tested with 3.11)
  • Remote SSH-reachable VM with Docker (for remote mode)
  • Optional Kibana via tools/docker-elk/ for visualization

⚡ Quick Start (Local Demo)

1. Prepare Python Environment

cd frontend
python3 -m venv .venv
source .venv/bin/activate
python setup.py  # creates requirements.txt, folders, config template
pip install -r requirements.txt

2. Start Local Elasticsearch

# Option A: Quick ephemeral ES
docker run --rm -p 9200:9200 \
  -e "discovery.type=single-node" \
  -e "xpack.security.enabled=false" \
  elasticsearch:8.15.0

# Option B: Use the ELK helper stack
# See tools/docker-elk/ for compose stack with Kibana

3. Configure the App

Edit frontend/config.py:

  • es_host: http://localhost:9200
  • es_auth: None for unsecured ES (or provide ("user", "pass"))
  • db_api_base: External registry API (optional)

4. Run the Portal

cd frontend
python app.py
# Portal: http://localhost:7000/esportal

5. Upload and Index

Upload CSV/JSON, add user queries (e.g., "red LED under 10W"), choose "Local" deployment. The pipeline will:

  • Infer schema and attribute fields
  • Create schemas/<index>-schema.json
  • Create index in local ES and bulk index documents

6. Query

Use the portal interface or connect the Search Agent.

☁️ Remote Deployment

When selecting "Remote" in the upload form, the pipeline will:

  1. SSH to VM: Stop existing containers, run elasticsearch:8.15.0 on first available port (9200-9299)
  2. Index Documents: Index uploaded documents into remote ES
  3. Deploy MCP Server: Build and run MCP container on ES_PORT+1000 with endpoints:
    • GET /health, GET /capabilities, GET /index-info
    • POST /search, POST /prompt

⚠️ Configuration Note

Update VM host/user/password in frontend/enhanced_data_pipeline.py and frontend/mcp_integration.py. Do not commit real secrets!

🤖 Search Agent (n8n) + Elastic MCP

  1. Import: Load search-agent/N8N - Search Agent.json into n8n
  2. Configure Model: Set up Claude/OpenAI credentials
  3. Set MCP URL: Use the MCP Server base URL from deployment
  4. Webhook: Portal's /ask endpoint calls n8n webhook

See search-agent/search-agent.md for detailed configuration steps.

⚙️ Configuration Guide

frontend/config.py

  • es_host, es_auth: Point to local ES for Local mode
  • db_api_base: External registry URL if using persistence
  • Replace placeholder cloud credentials with your values

Remote VM Requirements

  • Docker installed with sudo access
  • Open ports: 9200-9299, 10200-11299 (MCP uses ES_PORT+1000)
  • Update VM credentials in code before deployment

n8n Setup

  • Import flow and set model credentials
  • Configure MCP base URL from deployment logs

🔧 Troubleshooting

Flask starts but upload fails

Check that frontend/config.py exists and es_host is reachable for Local mode.

Local ES connection errors

Ensure Docker is running and port 9200 is open. Verify: curl http://localhost:9200

Remote mode stalls/fails

Verify SSH connectivity, Docker installation on VM, and required ports are open.

MCP health shows unhealthy

Check MCP /health URL from logs. Review container logs and confirm ES URL/index.

n8n webhook not reached

Confirm webhook URL is accessible from machine running the portal.
